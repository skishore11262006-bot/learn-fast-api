# FastAPI AI Learning

A beginner project built while learning AI Engineering — focused on APIs and FastAPI.

## What I learned
- What APIs are and why they power modern AI apps
- FastAPI — a fast, modern Python framework
- Building and testing endpoints

## Run locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

Open http://127.0.0.1:8000/docs to test the API.
